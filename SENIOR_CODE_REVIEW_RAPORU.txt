1. PROJE GENEL DEĞERLENDİRMESİ
================================================================================

Prestij Tütün, tütün sözleşmeli ekici anketlerinin tanımlanması, doldurulması,
cevaplanması, raporlanması ve yetkilendirilmesi için bir kurumsal yönetim
panelidir.

Teknoloji: React 19, TypeScript (strict), Vite 8, React Router 7, TanStack
Query 5, Zustand (persist), Axios, Tailwind CSS 4. Excel (xlsx-js-style),
PDF (jspdf + modern-screenshot), grafik (recharts).

Mimari (SPA):
  src/app            giriş, router, Query + Permissions sarmalayıcı
  src/features/*     iş modülleri (api → hooks → pages/components → utils)
  src/lib/api        Axios örneği, zarf çözme, hata normalizasyonu
  src/components     layout, UI, routing koruması
  src/stores         oturum (prestij-auth)
  src/config         menü ve sayfa başlıkları

Derleme: `tsc -b && vite build`. Geliştirmede `/api` ve `/uploads`
VITE_API_BASE_URL’e vekillenir (vite.config.ts).

Güçlü yanlar:
  - Feature klasörleri tutarlı (api/hooks/pages/utils).
  - HTTP çağrıları axios-instance yerine apiClient üzerinden (DIP).
  - İş kurallarının bir kısmı saf utils’te (görünürlük, doğrulama, tarih).
  - ~24 birim test dosyası yazılmış (ancak çalıştırılmıyor).

Zayıf yanlar:
  - Anket doldurma ve soru formu “tanrı bileşen”.
  - API PascalCase/camelCase köprüsü her feature’da kopyalanmış.
  - Seçenek grubu güncellemesi istemcide N+1 orkestrasyon.
  - Test hattı yok.
  - Geliştirme kimlik bilgisi kaynakta; örnek env’de dev-auth açık.
  - Ölü “son kayıtlar” zinciri ve kullanılmayan bileşenler.

Backend bu repoda yoktur. Tablo adları (TBL_D_ANKET_CEVAP, TBL_ANKET_SORU,
TBL_ANKET_ALT_SECENEK) yalnızca operasyonel bağlamda bilinmektedir; bu rapor
ön yüz koduna dayanır.
